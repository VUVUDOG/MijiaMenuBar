# 米家菜单栏 · 安装与使用

> **第三方工具，非小米官方。**

[下载最新版](https://github.com/VUVUDOG/MijiaMenuBar/releases/latest)。本说明对应 **v0.8.1**；截图沿用 v0.3.4 界面（演示数据），早于全屋设备、场景和新版面，仅供参考。

## 1. 准备

确认手机米家 App 能控制要使用的设备。日立中央空调需先在米家 → 连接三方平台 → 日立中央空调中输入日立智家账号完成关联。

## 2. 安装

 → 关于本机：M 系列选择 `arm64.zip`，Intel 选择 `intel.zip`。要求 macOS 13+。

解压，将 `MijiaMenuBar.app` 放入应用程序并打开。当前未公证，若系统提示无法验证开发者，确认来源后在「系统设置 → 隐私与安全性」选择「仍要打开」。

从旧版「日立空调」（`HitachiMenuBar.app`）升级：在旧版齿轮菜单选择「退出应用」，删除 `HitachiMenuBar.app`，再打开新版。登录状态会保留；如之前开启了「开机自动启动」，请在新版齿轮菜单重新打开一次。

## 3. 扫码登录

<img src="images/login-glass.png" alt="扫码登录入口（早期版本截图）" width="360">

点击菜单栏「米家」→「扫码登录米家」，用米家 App 扫描软件中的实时二维码并在手机确认。过期时重新发起扫码。每台 Mac 独立登录。

## 4. 控制面板

<img src="images/control-glass.png" alt="空调控制面板（早期版本截图，演示数据）" width="360">

| 位置 | 用法 |
| --- | --- |
| 顶部 | 标题与「全屋全关」按钮（点一次出现确认，3 秒内再点才执行）、齿轮菜单。 |
| 常用 | 右键设备「加入常用」后出现；单击开关，右键移出，可拖动排序。 |
| 场景 | 创建后出现；单击执行，场景启动后再点一次关闭；右键编辑或删除。 |
| 房间 | 一行显示全部房间，点击或按 ← / → 切换；绿点表示房间内有设备开着。 |
| 空调 | 所选房间有空调时显示：开关、− / + 调温（整数度）；点名称展开模式、风量与定时。 |
| 设备方块 | 单击开关；点右侧滑杆图标展开亮度、色温、窗帘开合、档位、定时等；按住拖动调整顺序；离线设备显示为灰色。 |
| 本房间「全关」 | 关闭本房间的灯、风扇、净化器、浴霸、净烟机和空调（不含插座、窗帘、电饭煲）。 |
| 右下角刷新 | 手动获取最新状态。 |
| 齿轮 | 新建场景、同步房间、重新登录、退出登录、外观、开机自动启动、检查更新、复制诊断、退出应用。 |

**场景**：齿轮菜单「新建场景…」→ 起名 → 「添加设备」逐个添加，或「录制开着的设备」把现在开着的全部放入 → 每个设备一行，可切换开 / 关或移出 → 保存。可放入灯、窗帘、插座、循环扇、净化器、浴霸、净烟机和空调，不含电饭煲。再点已启动的场景，会关闭它打开的设备（浴霸加热模式回到待机，窗帘不动）。场景只保存在这台 Mac。

**电饭煲**：点方块展开，选烹饪模式后点「开始烹饪」，按钮变成「确认开始」，4 秒内再点一次才会启动；开始前请确认锅内已放好米和水。可随时「停止烹饪」。

**定时关闭**：空调、灯、风扇、净化器、浴霸、净烟机、插座展开后可选 1 / 2 / 4 小时，方块上显示倒计时。由本应用计时，Mac 睡眠或应用关闭期间错过超过 2 小时的定时会作废。

**漏水提醒**：水浸传感器检测到漏水时发系统通知（首次使用请允许通知）、菜单栏显示「⚠︎ 漏水」、面板顶部出现红色提示；一直未干则每 30 分钟再提醒，恢复正常后通知一次。

**快捷指令**：在「快捷指令」App 的动作库搜「米家」，有「开关米家设备」「关闭房间」「设置空调温度」，可配合 Siri 或自动化使用；运行时应用会在后台自动启动。

所有操作点击后立即显示，后台并行同步；云端未确认时恢复原状态，底部提示原因。展开立即刷新，之后每 30 秒自动刷新；设备只读取当前房间。点击面板外或按 Esc 收起。

空调本身没有室温属性，室温和湿度来自同一米家房间的米家温湿度计。墙壁开关不接入，以免给智能灯断电；门锁、摄像机等安全类设备不接入。新增设备或调整米家房间后，点击齿轮菜单「同步房间」。

外观可在齿轮菜单「外观」选择跟随系统、浅色或深色，跟随系统时会随 macOS 日夜自动切换。

## 5. 钥匙串与账号

- 输入当前 Mac 的「登录」钥匙串密码，通常与本机登录密码相同。
- 确认为本软件请求后，「始终允许」记住授权；「允许」仅限本次。
- 退出应用保留凭证；退出登录清除凭证和设备缓存。
- 重新登录立即作废旧会话，取消扫码不会恢复旧账号。
- 开发签名更新可能重新申请授权。

## 6. 排查与更新

没有房间或设备时检查米家账号和手机设备列表，再「同步房间」。状态异常时看底部提示，检查设备在线并手动刷新。提示登录失效后重新扫码。

发现新版本时面板会出现「发现新版本」，点击「更新」自动下载、校验并重新打开；也可在齿轮菜单「检查更新」。校验不通过会取消安装，当前版本不受影响。每次更新后 macOS 会再要求一次钥匙串授权。登录过期时应用会提示并自动弹出扫码入口，扫码后设备列表会重新载入。

需要开机自动运行时，在齿轮菜单打开「开机自动启动」；首次开启如系统要求，在「系统设置 → 通用 → 登录项」中允许。

反馈时提供版本、Mac 芯片、macOS 版本、步骤和诊断信息。
